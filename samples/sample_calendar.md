# Sample Working Calendar (fictional)

Generic example calendar used by the demo and tests. Replace with your own
organisation's calendar. Only the table below is parsed.

## Calendar Rules

* Public holiday / Holiday / Company holiday: non-working day.
* Substitute working day: a weekend date treated as a normal working day.
* An unlisted Monday–Friday is a working day; an unlisted Saturday/Sunday is a weekend.
* Substitute working day status overrides normal weekend status.

## Canonical Date Records

| Date | Day | Status | Holiday or event |
|---|---|---|---|
| 2026-01-01 | Thursday | Public holiday | New Year's Day |
| 2026-06-17 | Wednesday | Company holiday | Example Mid-Year Holiday |
| 2026-06-20 | Saturday | Substitute working day | Example make-up working day |
| 2026-12-25 | Friday | Public holiday | Christmas Day |
| 2026-12-31 | Thursday | Company holiday | Example Year-End Holiday |
